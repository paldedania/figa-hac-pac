# figa-hac-pac

Seven MedRemind pages using HTML and CSS only. Open `index.html` to start.

- Root `index.html`: Today.
- Root `global.css`: shared colors, text, sidebar, cards and form styles.
- `01-today/style.css`: Today page styles. Images are in `01-today/assets/`.
- Folders `02` through `07`: one `index.html` and `style.css` per page.

HTML tags, attributes and CSS properties follow the [CodingGita course](https://github.com/codinggita/CGXSwarrnim/tree/main/Semester-1/HTML_CSS_JS). The site uses basic grids, flex layouts, media queries, forms and tables. HTML comments name every container and explain what it groups. Each CSS rule has a comment explaining where it is used and its purpose, including mobile and print rules.

This is a static layout. Save, dose and call buttons are disabled. Form fields, radio buttons and checkboxes are editable, but nothing is saved. Report previews use HTML `details` and `summary`. The medicine-list download is a normal HTML link. There is no JavaScript, framework or package setup.

Images and typography approximate the Figma design because exact asset exports were unavailable.
